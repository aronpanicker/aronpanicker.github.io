# aronpanicker.github.io

My personal website. Static HTML and CSS, no build step, no JavaScript, no
dependencies.

To work on it, open any `.html` file in a browser, or serve the folder:

```sh
python3 -m http.server
```

Every page shares `styles.css`. Posts live at the repo root as `movie-*.html`,
`book-*.html`, `blog-*.html`, and `recipe-*.html`, and are listed in
`posts.html`.
